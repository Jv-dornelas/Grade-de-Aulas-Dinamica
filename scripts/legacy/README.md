# Scripts históricos

Estes arquivos foram preservados como referência da população inicial, fora do código executado pelo Django.

- `popular_banco.py`: apaga cadastros antes de recriá-los. Não usar na base atual.
- `popular_dados_teste.py`: script antigo para shell, com gravações ao ser importado e horários diferentes da jornada atual. Não usar para os novos cenários.

A preparação atual utiliza comandos em `grade/management/commands/`, com os cuidados documentados em [AUTOMACAO.md](../../AUTOMACAO.md). Esta reorganização não executou nenhum script de população.
